# 대미궁 아비스 — Godot PC 프로토타입 v0.1.0

## 실행
1. Godot 4.3 이상 설치 (4.x GDScript 프로젝트)
2. Godot 프로젝트 매니저에서 `project.godot`가 있는 폴더를 Import
3. F6이 아닌 **F5 (프로젝트 실행)** 또는 우측 상단 ▶ 실행

## 조작
- WASD / 방향키: 상하좌우 한 칸 이동
- E: 인접한 보물상자 열기
- F5: 게임 저장 (탐사 중)
- F9: 게임 불러오기 (탐사 중)
- 전투: 화면 버튼 클릭

## 구현됨
- 고정된 17×13 격자 초원, 벽과 미탐색 안개
- 첫 방문 활동 증가, 활동 10회마다 야영
- 회색 늑대와 슬라임 전투, AP 2.0, 공격/정수스킬/방어/도주/턴종료
- EXP, 골드, 레벨업, 상자, 로컬 JSON 저장

## 다음 버전 예정
- 11부위 장비 UI와 장비 스탯 계산
- 정수 장착·드롭·인벤토리·넘버즈 데이터
- 정식 몬스터 턴/AP, 물리방어/치명타/상태이상 공식
- 맵 랜덤 생성, 다중 지역, 타일 에셋

## 주의
- 이 프로젝트는 초기 플레이 가능한 프로토타입으로 전체 게임 설계의 완성 구현이 아닙니다.
- 적 AI는 1회 반격으로 단순화했으며, 초기 HP/MP와 레벨업 공식도 임시값을 포함합니다.
- 엔진 실행 검증은 별도로 수행되지 않았습니다.
